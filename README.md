## Lite 為什麼便宜：1Gbps 與 2T 流量換來的是國際線路

香港機房的頻寬成本高，同配置通常比美國貴。DMIT 能在 $6.9 給出 1Gbps 加 2T 月流量，靠的是線路定位。

Lite 上線時的第三方測評寫明，它接入的是 NTT、PCCW、Cogent、Telstra、HKIX、EIE 這類國際線路，非中國路由優化，電信與聯通方向繞日本 NTT，商家只保證不繞美國。評測還直接建議「期望中國路由優化的用戶請選 HKG.Pro 方案」。這與 Standard 系列「主打國際訪問」的定位對得上。

對誰是好事：訪客在東南亞、歐美、香港本地，或你只是拿它做代理出口、API 中轉、跑國際業務，繞不繞大陸無所謂，1Gbps 和 2T 就是實打實的資源。對誰是坑：網站訪客集中在中國大陸，晚高峰走國際線路繞一圈回來，體驗不會比一台幾十元的大陸優化小機器好。

## 月付與年付的差別不在價格，在 IP 保障

這是多數榜單不會寫的一條，但它直接影響你買哪個計費週期。

第三方匯總轉述的 DMIT 條款口徑是：月付購買時不保證 IP 對大陸區域可用；可以額外花 **1 美元**（Guarantee + 費用）保證 IP 對亞洲可用；購買 **3 個月或年付**時才保證 IP 對大陸可用，IP 有問題聯繫客服免費更換。個人使用導致 IP 出問題，申請更換 IP 收 **$5/次**。

換句話說，月付加 $1 買到的是「亞洲可用」，不含大陸；想讓大陸方向有保障，計費週期得拉到 3 個月或年付。如果你打算月付又默認「反正能連」，這個默認沒有依據。

官方 TOS 摘要對換 IP 另有細則，且與上面的「免費更換」口徑不完全一致：Tier 1 網絡僅支持付費換 IP（$5/次），需購買滿 24 小時、距上次換 IP 滿 3 天、剩餘時長不少於 3 天；高級版與 Eyeball 網絡才有所謂免費更換，條件是購買滿 7 天、距上次換 IP 滿 15 天、ICMP 及所有 TCP 端口被屏蔽、剩餘時長不少於 7 天。IP 由系統隨機分配，不指定地區或具體 IP，換完不可撤銷。

Lite 屬哪一類網絡，兩份資料沒給出一致答案。下單前用客服確認你的方案走哪套換 IP 規則，這一步花五分鐘，比事後爭論值錢。

## 退款窗口與流量重置：條款裡藏著的真實成本

## 下單前要確認的五件事

1. **計費週期與續費價**：$6.9 與 $12.9 是月付標價，年付或季付的實際單價與續費價，下單頁會顯示，別只看首期。
2. **IP 保障級別**：月付不保證大陸可用，加 $1 只保亞洲，3 個月或年付才保大陸。你的用途屬於哪一種，先想清楚。
3. **換 IP 規則**：$5/次是通用價，免費更換只存在於特定網絡與特定條件下，Lite 屬於哪一類要問客服。
4. **退款邊界**：3 天內、30GB 內可全額退，扣手續費；IP 地區問題不在退款理由裡。
5. **付款方式**：支付寶、信用卡、PayPal 等管道都有資料提及，各來源列法不完全一致，以結帳頁實際選項為準。

## FAQ

**香港 VPS 需要備案嗎？**
不需要。香港不在大陸備案範圍內，部署環境相對自由，這也是香港機房對建站用戶的主要吸引力之一。

**$6.9 的 Lite 能建站嗎？**
看訪客在哪。訪客在歐美、東南亞或香港本地，1Gbps 加 2T 綽綽有餘。訪客主要在大陸，國際線路繞行加上月付 IP 不保證大陸可用，不建議。

**月付和年付到底差在哪？**
差在 IP 保障與單價。月付不保證 IP 對大陸可用，加 $1 保亞洲；3 個月或年付才保證大陸可用。年付單價更低，但要先確認續費價，別用首期價推算長期成本。

**換一次 IP 多少錢？**
$5/次，且要滿足購買時長、距上次換 IP 間隔、剩餘時長等條件。個人使用導致 IP 出問題也按這個收。

**流量用完了怎麼辦？**
現有活動是每次重置恢復基礎流量的 20%，有效期前最多 2 次，2026 年 12 月 31 日截止，在控制面板自行操作。真的長期不夠，該考慮的是升到 STARTER 而不是反覆重置。
